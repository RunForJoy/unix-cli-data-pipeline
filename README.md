# UNIX Command Line Tools for Data Science

Конвейер сбора, преобразования, очистки и первичного анализа данных о вакансиях с помощью стандартных утилит командной строки UNIX (`curl`, `jq`, `sort`, `uniq`, `sed`, `awk`, `cat`) без использования тяжелых фреймворков.

##  Стек и инструменты
* **Shell / CLI:** `/bin/sh`, Bash
* **Сбор и парсинг данных:** `curl`, `jq` (HeadHunter API)
* **Обработка и агрегация:** `sort`, `uniq`, `sed`, `awk`, `cat`, `head`, `tail`

---

##  Структура проекта и описание задач

Весь исходный код и сгенерированные артефакты расположены в директории `src/` и разбиты на 6 последовательных этапов обработки данных:

### `ex00/` - Сбор данных через API (`hh.sh`)
* **Задача:** Взаимодействие с публичным API HeadHunter для выгрузки информации о вакансиях по поисковому запросу (по умолчанию `"data scientist"`).
* **Реализация:** Исполняемый shell-скрипт `hh.sh` принимает название вакансии в качестве аргумента, запрашивает первые 20 релевантных позиций и форматирует JSON-ответ через `jq` так, чтобы каждое поле располагалось на новой строке.
* **Результат:** `hh.json`.

### `ex01/` - Преобразование JSON в CSV (`json_to_csv.sh`, `filter.jq`)
* **Задача:** Конвертация вложенной JSON-структуры в плоский табличный формат CSV для дальнейшего анализа.
* **Реализация:** Скрипт `json_to_csv.sh` применяет отдельный фильтр `filter.jq` к файлу `hh.json`, извлекая 5 целевых столбцов (`id`, `created_at`, `name`, `has_test`, `alternate_url`) и формируя строку заголовков.
* **Результат:** `hh.csv`.

### `ex02/` - Многоуровневая сортировка (`sorter.sh`)
* **Задача:** Упорядочивание табличных данных с сохранением заголовка в первой строке.
* **Реализация:** Скрипт `sorter.sh` с помощью базовых утилит (`cat`, `head`, `tail`, `sort`) сортирует записи из `hh.csv` по возрастанию даты публикации (`created_at`), а при совпадении дат — по идентификатору вакансии (`id`).
* **Результат:** `hh_sorted.csv`.

### `ex03/` - Очистка и нормализация текстовых полей (`cleaner.sh`)
* **Задача:** Извлечение грейда специалиста из сырых названий вакансий и удаление информационного шума.
* **Реализация:** Скрипт `cleaner.sh` парсит столбец `name`, выделяя ключевые уровни (`Junior`, `Middle`, `Senior`) или их комбинации (например, `Middle/Senior`). Если грейд в названии не указан, значение заменяется на `"-"`.
* **Результат:** `hh_positions.csv`.

### `ex04/` - Описательная статистика (`counter.sh`)
* **Задача:** Оценка распределения вакансий по грейдам.
* **Реализация:** Скрипт `counter.sh` подсчитывает количество уникальных значений в очищенном столбце `name` и сортирует итоговую сводку по убыванию частоты.
* **Результат:** `hh_uniq_positions.csv`.

### `ex05/` - Партиционирование и конкатенация данных (`partitioner.sh`, `concatenator.sh`)
* **Задача:** Разбиение датасета на партиции по дате и обратная сборка в единый файл.
* **Реализация:**
  * `partitioner.sh` разбивает `hh_positions.csv` на отдельные CSV-файлы по дате из столбца `created_at` (сохраняя заголовки в каждом файле).
  * `concatenator.sh` объединяет все созданные партиции обратно в единый CSV-файл, полностью идентичный исходному.

##  Запуск скриптов

Все скрипты являются исполняемыми (`chmod +x`) и используют стандартный интерпретатор `/bin/sh`. Пример последовательного запуска конвейера из директории `src/`:

```bash
cd src/ex00 && ./hh.sh "data scientist"
cd ../ex01 && ./json_to_csv.sh
cd ../ex02 && ./sorter.sh
cd ../ex03 && ./cleaner.sh
cd ../ex04 && ./counter.sh
cd ../ex05 && ./partitioner.sh && ./concatenator.sh
```
